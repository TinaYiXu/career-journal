# 求职日志

独立静态页面，通过 GitHub Pages 发布。

投递、复盘与 offer 数据存储在当前浏览器的 localStorage 中，不会同步到 GitHub，也不会跨设备同步。原页面的本地数据不会自动迁移到新的站点地址。

发布：将 index.html 和 .nojekyll 放入仓库 main 分支根目录，在 Settings → Pages 选择 Deploy from a branch、main、/(root)。


数据保护：
- 顶部“导出备份”下载包含全部投递、复盘、Offer 和权重的 JSON 文件。请确认下载完成，并将文件存到可靠位置。
- “导入备份”校验后替换全部数据，请先导出当前备份。
- “撤销删除”按倒序恢复本次页面打开期间的删除，包含投递关联的复盘及 Offer；刷新后撤销历史清空。
- 保存成功显示绿色提示，失败显示红色提示；失败的修改不会写入存储。
- 本功能不提供云端备份，清除浏览器网站数据后需要通过备份文件恢复。
